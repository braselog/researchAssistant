# Durable Research Notes

Use this directory only for project context that is worth preserving but does not belong in tasks, decisions, activity logs, methods, or other documentation.

- Hooks never write directly here.
- `/wrap_up` may propose a note after resolving the daily context inbox.
- Reuse an existing topic file rather than creating one per conversation.
- Keep accepted conclusions and rationale in decision records, not informal notes.
- Keep completed work in the activity log and actionable work in tasks or GitHub.
