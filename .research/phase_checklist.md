# Research Phase Guide

Research is iterative. These readiness indicators help identify missing foundations; they are not rigid gates. Document justified exceptions and move backward when new evidence exposes methodological problems.

## Current emphasis: Setup

## Setup
- [ ] Repository, environment, and version control are usable
- [ ] Sensitive data and credentials are excluded appropriately
- [ ] Data storage and provenance approach is defined
- [ ] Project README reflects the actual project

## Planning
- [ ] Research question, aims, outcomes, and independent units are defined
- [ ] Relevant prior evidence has been assessed
- [ ] Key assumptions, risks, controls, and alternatives are documented
- [ ] Planned analyses can answer the stated questions

## Development
- [ ] Core pipeline behaviour is implemented without silent fallbacks
- [ ] Parameters, dependencies, inputs, and outputs are explicit
- [ ] Critical behaviour has realistic tests or validation fixtures
- [ ] DVC or the chosen workflow captures reproducible stages where appropriate
- [ ] Methods are being kept aligned with implementation

## Analysis
- [ ] Inputs and provenance are verified
- [ ] Experimental units, dependence, leakage, exclusions, and confounding are addressed
- [ ] Diagnostics and sensitivity analyses match the design
- [ ] Results and figures are generated by reproducible code
- [ ] Important findings include uncertainty and limitations

## Writing
- [ ] Background claims use verified literature
- [ ] Methods reflect current implementation and pipeline state
- [ ] Results use current machine-readable evidence
- [ ] Figures, captions, and prose agree
- [ ] Manuscript claims are linked in the evidence map

## Review
- [ ] Major validity and reproducibility risks are resolved or disclosed
- [ ] A clean reproduction has been performed where feasible
- [ ] Reporting and venue requirements are met
- [ ] Data, code, and materials availability are documented
- [ ] Collaborator approval and submission materials are complete where applicable
